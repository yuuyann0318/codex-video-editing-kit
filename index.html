店主の撮影素材を、投稿できる動画へ仕上げる

小さなお店の店主が、料理と店内をスマホで撮影しました。

Instagramのリールへ載せたい。でも、言い直した所を切り、字幕を入れ、音量を整える時間がありません。

そこで、短尺動画の編集を依頼します。

編集する人は、台本、撮影済み動画、参考動画、完成後の長さ、投稿先を受け取ります。不要部分を切り、字幕と音量を整えます。スマホなどで再生できるMP4形式の動画ファイルを、最初の確認用の版「初稿」として渡します。

店主が確認し、合意した範囲を修正します。最後に、Instagramへ投稿できる完成MP4を納品します。

依頼主がお金を払う対象は、確認を終えた完成動画と、条件に沿って修正・納品する作業です。

このキットは、文字起こし、時刻つき字幕、定型のカット、画像配置、MP4書き出しを助けます。素材の権利、台本の内容、字幕、音、映像の確認は人が行います。

自分の動画を作る時と、受託の違い

自分のSNS動画なら、尺や修正回数を自分で決められます。

依頼主の動画を編集する時は、完成後の長さ、画面の向き、字幕、BGM、初稿期限、修正回数、納品形式、素材の扱いを先に合意します。

「動画が書き出せた」だけでは納品できません。

依頼条件に合い、最初から最後まで再生し、依頼主が確認できるファイルへする所までが仕事です。

依頼から報酬まで

クラウドワークスの固定報酬制プロジェクトを使う架空例です。

  1. 「ショート動画 編集」「リール 動画編集」で募集を探す
  2. 素材尺（受け取る動画の合計の長さ）、完成尺（完成後の長さ）、本数、編集範囲、期限を読む
  3. 自主制作の見本と、担当できる範囲を書いて応募する
  4. 納品物、修正、AI利用、素材の扱い、報酬を合意する

Codexを初めて使う方へ

Codexは、ChatGPTデスクトップアプリのメニューから選べる作業画面です。この特典では、選んだフォルダの素材やキットを読み、自然な文で動画編集を頼むために使います。

OpenAI公式：ChatGPT／Codexクイックスタート

Macでは、次の順に始めます。

  1. 公式クイックスタートからChatGPTデスクトップアプリを入れる
  2. ChatGPTアカウントでサインインする
  3. 作業するフォルダを開く
  4. ChatGPTの選択メニューからCodexを選び、新しいチャットを開く

この動画キットの実機検証は、下に記載するCodex CLI 0.165.0で行いました。ChatGPTデスクトップアプリはOpenAI公式の開始経路ですが、このキットの導入から書き出しまでを同アプリの画面だけで行う手順は、別に実機確認していません。

デスクトップアプリの表示、利用可否、上限は、現在の公式案内と自分のアカウント画面で確認してください。現在の契約に含まれるとは断定しません。

対応している環境

導入、2種類の見本作成、自動文字起こし、字幕修正、再書き出しまで実機確認した環境は、Apple Silicon搭載Macです。

2026年10月29日時点の確認環境です。

  • macOS 27.0.1
  • Apple Silicon搭載Mac
  • Python 3.9.6
  • Codex CLI 0.165.0
  • FFmpeg 9.0.2（動画を書き出す道具）
  • FFprobe 9.0.2（動画の長さや音声の有無を調べる道具）

用意するものは、Apple Silicon搭載Mac、Codexを開けるChatGPTアカウントまたは確認済みのCodex CLI、配布ZIP、初回取得時のインターネット接続、3GB以上の空き容量です。

同梱見本の再生と作り直しだけなら、音声認識モデルの追加取得はありません。自分の音声を初めて文字起こしする時は、専用環境とモデルを取得します。
